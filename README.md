# ⚡ ES-Manager (Portable Desktop Software)

**ES-Manager** হলো **Rust** এবং **Tauri v2** ফ্রেমওয়ার্ক ব্যবহার করে তৈরি একটি সুপার-ফাস্ট, আধুনিক ও পোর্টেবল ডেক্সটপ সফটওয়্যার। এটি অফলাইন-ফার্স্ট আর্কিটেকচারে লোকাল **SQLite** ডাটাবেস এবং ক্লাউড ব্যাকআপের জন্য **Turso (libSQL)** সিঙ্ক্রোনাইজেশনের সাথে রিয়েল-টাইম পুশ ও উইন্ডোজ নেটিভ নোটিফিকেশনের জন্য **ntfy.sh** ব্যবহার করে।

---

## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

### ১. ডুয়াল ড্যাশবোর্ড (Dual Dashboards)
- **Admin Dashboard**:
  - অ্যাডমিন পাসওয়ার্ড দিয়ে নিরাপদ লগইন (ডিফল্ট: `admin` / `admin123`)।
  - ইউজার ম্যানেজমেন্ট: নতুন ব্যবহারকারী তৈরি (Username ও Password সহ)।
  - টাস্ক অ্যাসাইনমেন্ট: একসাথে এক বা একাধিক ইউজারকে (Multiple Users) কাজ এসাইন করার সুবিধা।
  - আধুনিক **Date Picker** এবং **Time Picker** দিয়ে কাজের সুনির্দিষ্ট ডেডলাইন নির্ধারণ।
  - কাজের গুরুত্ব বা প্রায়োরিটি নির্ধারণ (Low, Medium, High)।
  - ইউজারের কাজের অগ্রগতির রিয়েলটাইম মনিটরিং ও ফিল্টারিং।

- **User Dashboard**:
  - ইউজারের জন্য নির্ধারিত কাজগুলোর তালিকা এবং ডেডলাইন ডিসপ্লে।
  - এক ক্লিকে কাজের স্ট্যাটাস আপডেট: **Pending** ➔ **In Progress** ➔ **Completed**।
  - স্ট্যাটাস পরিবর্তনের সঙ্গে সঙ্গে অ্যাডমিনের কাছে স্বয়ংক্রিয় নেটিভ ডেক্সটপ নোটিফিকেশন প্রেরণ।

### ২. নোটিফিকেশন সিস্টেম (ntfy.sh & Native Windows Toast)
- অ্যাডমিন কাজ এসাইন করার সঙ্গে সঙ্গে ইউজারের কম্পিউটারে উইন্ডোজ সিস্টেম ট্রের মাধ্যমে **Native Desktop Notification** চলে যাবে।
- ইউজার কাজ শুরু বা সম্পন্ন করলে অ্যাডমিনের কাছে নোটিফিকেশন যাবে।
- ইন-অ্যাপ নোটিফিকেশন টোস্ট এবং উইন্ডোজ ১১/১০ নেটিভ টোস্ট অ্যালার্ট।

### ৩. অফলাইন-ফার্স্ট ডাটাবেস ও Turso ক্লাউড সিঙ্ক
- সম্পূর্ণ **SQLite (WAL Mode)** লোকাল ডাটাবেস — ইন্টারনেট সংযোগ ছাড়াই পূর্ণ কার্যক্ষম।
- [Turso.tech](https://turso.tech) ক্লাউড ইন্টিগ্রেশন: ইন্টারনেট থাকলে ব্যাকগ্রাউন্ডে স্বয়ংক্রিয় সিঙ্ক (Bidirectional Sync)।
- সেটিংস প্যানেল থেকে সহজে Turso URL ও Auth Token যুক্ত বা পরিবর্তন করার সুবিধা।

### ৪. সুপার ফাস্ট ও পোর্টেবল (Super Fast & Portable)
- **পোর্টেবল ভার্সন**: [`ES-Manager-Portable.exe`](./ES-Manager-Portable.exe) (কোনো ইনস্টলেশন ছাড়াই সরাসরি রান করে)।
- **স্ট্যান্ডার্ড ইনস্টলার**: [`ES-Manager-Setup.exe`](./ES-Manager-Setup.exe) (ডেস্কটপ ও স্টার্ট মেনু শর্টকাট সহ ইনস্টল করার জন্য)।
- মেমোরি খরচ অতি নগণ্য (মাত্র ৩০-৫০ মেগাবাইট র‍্যাম)।

## 💻 কীভাবে সফটওয়্যারটি চালাবেন?

1. **সরাসরি পোর্টেবল অ্যাপ্লিকেশন চালানো**:
   - ফোল্ডারে থাকা **`ES-Manager-Portable.exe`** ফাইলে ডাবল-ক্লিক করলেই সফটওয়্যারটি ওপেন হবে।
2. **ইনস্টলার দিয়ে ইনস্টল করতে চাইলে**:
   - **`ES-Manager-Setup.exe`** ফাইলে ডাবল-ক্লিক করে কয়েক সেকেন্ডেই ইনস্টল করে নিতে পারবেন।
3. **ডেভেলপমেন্ট মোডে চালানো (Live Development)**:
   ```powershell
   npm run tauri dev
   ```
